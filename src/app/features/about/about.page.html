SECURITY BY DESIGN

Segurança e limites

Não existem credenciais embutidas no código do navegador. Para execução real, o servidor exige ativação explícita, código de acesso e variável secreta Gemini.

  • Exemplos sintéticos e nenhuma dependência de sistemas internos.
  • Modo demo determinístico, sem alegar processamento por IA.
  • Sem banco de dados: histórico local, limitado a 12 resultados.
  • Sem autenticação pública de usuários; live restrito por código.
  • Análises são sugestões, não diagnósticos garantidos.
